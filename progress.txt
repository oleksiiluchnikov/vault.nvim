- Key patterns for new tests:
  - Commands that use `vim.fn.input`, `vim.ui.select`, or `vim.fn.confirm` for interactive
    dialogs can't be tested via `:Vault` commands in headless mode. Use the underlying
    API functions (Note:delete, Note:move, etc.) or driver.lua to bypass the dialog.
  - Commands that need specific config (journal.daily dir, .base files) must set the config
    via `driver.lua` before running the command.
  - Pickers that may return 0 results should use `pcall(vim.cmd, ...)` in driver.lua
    and check `ok ~= false` rather than waiting for TelescopePrompt filetype.
  - grep picker has a real bug: `grep/init.lua:8` attempts to index nil when no
    live_grep extension is available. Tracked as known issue.
